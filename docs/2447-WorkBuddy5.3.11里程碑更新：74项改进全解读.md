# WorkBuddy 5.3.11里程碑更新：74项改进全解读

> 原文链接：[https://www.laoshoucun.com/workbuddyzl/2447](https://www.laoshoucun.com/workbuddyzl/2447)

<p>一个版本塞74条更新是什么概念。按常规节奏，10到15条已经算大版本，2026年8月7日，WorkBuddy发布5.3.11：18项新增和6项优化，50项bug修复。我打开更新清单，一条条往下翻，翻到那50项修复才明白，这次的重心根本不在新功能上。</p>
<p>先看新增的18项往哪使劲。企业协作这边，Teams免审加入和企微微信助理的流式输出，技能体系这边，本地搜索和开关toast反馈，文件管理这边，资料库deeplink和Markdown预览，体验打磨这边，对话运行时间显示和任务批量操作。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/2026/08/20260816221240_366853.png" alt="WorkBuddy 5.3.11里程碑更新" style="max-width:100%;height:auto;border-radius:8px;margin:16px 0" /></p>
<p>先说最痛的，50条修复，我捞几条重点：DeepSeek自定义模型对话回复为空，升级后本地助理聊天记录丢失，发消息后任务卡在思考中，重启后聊天历史记录整片消失，全是直接砸核心体验的狠问题，聊天记录丢失这条，谁踩过谁知道。那种绝望。</p>
<p>从修复的方向看，WorkBuddy这回集中清了一波技术债，我数了下，74条里50条是修复而不是新功能，说明团队在加新东西和修旧毛病之间，把后者排在了前面。对一个快速更新的AI工具，这个选择值得点个头。功能可以慢慢堆。稳定性才是用户留得下来的地基。</p>
<p>新增功能里，我第一眼盯上的是企微和微信助理。逐字流式输出上线，回复过程实时可见，此前助理的回复要等整段生成完才亮出来，等待期间进度全靠猜，体验就是一场加载中的黑箱，现在回复像打字一样一句句冒出来，方向对不对，你能提前看出来。</p>
<p>另一个新增很贴日常干活的样子：先发文件后补文字描述，可以先传一个文件过去，再补一句要怎么处理，不必把文件和指令挤在同一条消息里，文件先扔过去，想明白了再下命令，用惯之后会发现，这个顺序比想象中贴心。</p>
<p>Teams拉人，不用等审核了，以前走邀请链接进Teams项目，可能要等管理员点审核，现在链接本身带授权信息，点开即进，要快速拉临时项目班的话，等审核那段空转时间被抹掉了。配合新增的账户昵称修改和开机自启动设置，团队协作的完整性和顺手度都有长进，这些点看着细碎，叠起来就是更顺滑的企业使用体验。</p>
<p>技能管理这边，“我安装的技能”页面加了本地搜索框，装了一堆技能也能一找就准。技能开关切换后补了toast反馈，切完不用再猜生效没生效，装过几十个技能的人都知道前一条有多救命。文件管理这边，资料库支持deeplink直开指定文档，Python类连接器有了运行时支持，对话流加了每轮运行时间显示，任务列表支持批量删除和批量归档，任务攒成山的用户，用得上。</p>
