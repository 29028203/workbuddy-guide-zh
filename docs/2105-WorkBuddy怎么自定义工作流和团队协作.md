# WorkBuddy怎么自定义工作流和 团队协作

> 原文链接：[https://www.laoshoucun.com/workbuddyzl/2105](https://www.laoshoucun.com/workbuddyzl/2105)

<p>WorkBuddy 核心价值就是工作流和团队协作。</p>
<p>怎么自定义工作流，什么情况下，可以使用自定义工作流。</p>
<p>比如“报销审批”从提交到审核再到打款，每一步都可以设置执行人、条件，超时提醒。这样流程自动流转，不用来回催。</p>

<p>分支判断也很重要，根据不同情况自动走不同路线，例如报销超过阈值就自动升级审批。</p>
<p>团队协作方面，任务看板能清楚看到每个人的进度，评论@功能减少来回沟通。任务完成情况会自动统计，为绩效提供数据。整体用下来，团队流程会非常顺。</p>
