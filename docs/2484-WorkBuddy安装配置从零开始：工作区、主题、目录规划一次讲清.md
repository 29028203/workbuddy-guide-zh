# WorkBuddy安装配置从零开始：工作区、主题、目录规划一次讲清

> 原文链接：[https://www.laoshoucun.com/jiaocheng/2484](https://www.laoshoucun.com/jiaocheng/2484)

<p>第一次打开 <a href="https://www.laoshoucun.com/workbuddy" target="_blank" rel="noopener">WorkBuddy</a>，很多人的第一反应是直接开聊。先忍住。这类 <a href="https://www.laoshoucun.com/" target="_blank" rel="noopener">AI办公</a>工具最经典的翻车剧本是：装完就用，用了半个月，某天换电脑，发现对话记录、技能，连接器全留在旧机器里，一切从头再来。把&#8221;家&#8221;先安顿好，再开干，这期一次讲完。这剧本我见得太多，都懒得惊讶了。</p>
<p>安装环节没有悬念。桌面客户端覆盖 Windows 和 macOS，官网下对应系统的包，双击跟着提示走，装完任务栏常驻。启动后登录，第一件事是建工作区。可以把它想成一个超大文件夹：对话、生成的文件，配置全在里头，工作区之间互相隔离。老手的做法是先开一个&#8221;测试工作区&#8221;随便折腾，弄乱了不心疼，正式的事另起一个干净的。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/2026/08/20260817121044_118736.png" alt="WorkBuddy安装配置"></p>
<p>接着要认几个目录，平时用不着，出事时找不到会抓瞎。头一个是 ~/.workbuddy/，用户级配置根目录，里面放 mcp.json（连接器配置）、MEMORY.md（长期偏好），skills/（技能），workbuddy.db（自动化数据）。说它是这套系统的&#8221;大脑皮层&#8221;不夸张，备份主要就备这个文件夹。第二个是每个项目内的 .workbuddy/，存工作区自己的项目数据，注意它不是临时缓存，千万别删，删了等于把对话史和配置一起扔掉。第三个是托管运行时，Node、Python 这些被安置在 ~/.workbuddy/binaries/ 的隔离目录，不碰系统环境，重装系统前记得连它一起搬走。</p>
<p>初始化没多复杂，三件事：建测试工作区练手。把左侧栏里&#8221;专家&#8221;&#8221;连接器&#8221;&#8221;技能&#8221;三个入口的位置认熟。发一条指令看能不能正常应答。装完别急着去试高级玩法，先跑三步自检，比读十篇教程都管用。让它新建一个文本文件写上 hello，看文件是否真的落地。告诉它&#8221;记住我常用 Windows&#8221;，关掉程序重开，再问它你用什么系统，看记忆还在不在。切一次深色主题，看界面跟不跟。三关全过，环境就算稳了。</p>
<p>日常使用再送两条习惯。工作区按用途拆：个人琐事一个、工作项目一个，学习一个，各自的记忆互不掺和。项目收尾后整个文件夹归档，日后翻历史清清楚楚。换机或重装前，把 ~/.workbuddy 整个文件夹拷去移动硬盘或网盘，体积不大，装着你全部的配置和记忆，新机恢复时原样放回去，环境立刻如旧。这步最容易被跳过，等装完新系统才发现偏好全没，再后悔就晚了。</p>
<p>说句收尾的话：这类工具的上手难点从来不是&#8221;会不会用&#8221;，而是&#8221;一开始有没有摆对位置&#8221;。配置一次，长期受益。安顿好了，下一站就可以放心去摸核心功能了。前期花的那半小时，后面省下的可能是三天。</p>
