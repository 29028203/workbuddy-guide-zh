# WorkBuddy Mac安装教程：苹果电脑怎么装

> 原文链接：[https://www.laoshoucun.com/jiaocheng/2971](https://www.laoshoucun.com/jiaocheng/2971)

<p>Mac 装 <a href="https://www.laoshoucun.com/workbuddy" target="_blank" rel="noopener">WorkBuddy</a>，先认芯片再选包，这是跟 Windows 最大的区别。系统要求 macOS 12（Monterey）及以上，低于这个版本官方不支持。</p>
<p>下载的时候要选对版本。打开官网点「下载 WorkBuddy」，看清楚自己的芯片：M 系列芯片选 Mac ARM64 版本，Intel 芯片选 Mac X64 版本。不知道自己是哪种芯片，点左上角苹果图标，选「关于本机」就能看到，处理器那一栏写得清清楚楚。选错了装不上，别猜。</p>
<p><img loading="lazy" decoding="async" src="https://cdn.laoshoucun.com/web/2026/09/20260902154331_958106.png" alt="WorkBuddy Mac界面" width="600" height="395"></p>
<p>安装比 Windows 还省事。双击下载好的 .dmg 文件，会弹出一个安装窗口，把 WorkBuddy 图标拖进 Applications 文件夹，等拷贝完成就行。完事再把挂载的磁盘映像推出，下载目录里那个 .dmg 文件用不上了也可以删掉。</p>
<p>登录还是微信扫码。通过启动台打开，或者按 Command 加空格 搜 WorkBuddy。点「登录」，浏览器会自动打开登录页，勾上《服务条款》和《隐私协议》，微信扫一下码，登录成功自动跳回客户端。</p>
<p>更新在个人中心里。点左下角「个人中心」，找到「检查更新」，系统会自动检测并完成升级。</p>
<p>Mac 这边整个安装就是拖一下图标的事，比 Windows 少点几次下一步。唯一容易卡住的是选错芯片版本，安装前花十秒看一眼「关于本机」，后面全顺。</p>
