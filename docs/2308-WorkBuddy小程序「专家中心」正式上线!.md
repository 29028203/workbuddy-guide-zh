# WorkBuddy 小程序「专家中心」正式上线!

> 原文链接：[https://www.laoshoucun.com/workbuddyzl/2308](https://www.laoshoucun.com/workbuddyzl/2308)

<p>WorkBuddy<br />
2026年4月16日，针对WorkBuddy小程序，本次更新重点新增三大核心功能，分别是专家中心、分享入口及朋友圈转发弹窗，同时同步添加服务号引导横幅，进一步提升用户触达效率与分享便捷度。此外，对电脑模式的连接稳定性进行了优化，新增HTML素材导入支持，同时细化多项使用细节的交互设计，让整体操作更流畅，更贴合用户使用习惯。</p>
<p>CLI模块：全面升级，效率倍增</p>
<p>CLI模块迎来全方位升级，首先全面优化Memory系统，大幅强化AI的上下文理解能力，让交互更精准，更贴合用户需求。新增<a href="https://www.laoshoucun.com/">Agent</a> Fork模式与对话分支功能，有效优化并行任务的处理效率，提升多任务操作体验。同时，正式上线Daemon守护进程，可实现后台任务的全生命周期可视化管理，从任务启动、运行到结束全程可控，大幅提升开发运维效率，有效降低操作成本。</p>
