# WorkBuddy连发两版：移动端协同与灵感分享体验升级

> 原文链接：[https://www.laoshoucun.com/workbuddyzl/2448](https://www.laoshoucun.com/workbuddyzl/2448)

<p>我翻了 WorkBuddy 最近两个版本的更新日志，5.3.12 和 5.3.13 是连着两天发的，8 月 12 日一个、13 日一个，一个 15 条更新一个 12 条。软件产品连续两天发版不常见，通常意味着头一天引入新功能后，第二天赶紧把冒出来的问题修掉。这两个版本的核心都落在两件事上，移动端协同体验升级，和灵感分享功能完善。</p>
<p>移动端协同这轮主要修弱网和休眠。以前手机连着电脑，网络一波动或者电脑进休眠，恢复之后经常断连、消息不同步，5.3.12 针对这类问题做了专项优化。同版本还修了一串相关毛病：休眠恢复或弱网启动后界面长时间白屏转圈、创建会话超时，本地助理内存涨太快导致白屏崩溃，本地助理重启后任务上下文丢了没法继续执行，允许锁屏远程重启后状态丢失导致远程访问失效，这几条基本都是用户吐槽最多的。这些修复指向同一个目标，让手机和电脑的配合像本地操作一样稳定，对经常在外面用手机远程操控电脑的人来说，直接影响每天用不用得顺。</p>

</p>
<p>灵感分享是另一个重头。5.3.12 加了口令分享，复制一段口令发给别人，对方输进去直接跳到对应的灵感详情页。5.3.13 又推了一键做同款，支持快速套版复刻网页。灵感这功能可以理解成预设的任务模板，比如生成周报、制作数据看板，保存下来自己和别人都能复用。口令加一键同款这套组合，让灵感的传播像发小程序一样简单，发个口令对方一点就能用。过去不擅长写提示词的人要自己摸索怎么配置工作流，现在直接借用别人跑通的模板，改一改就能用，门槛一下子低了不少。</p>
<p>细节上两个版本也磨了不少。5.3.12 优化了输入框和模型选择菜单的样式，输入区边界和浮层层级更清楚，这种 UI 打磨不影响功能，但直接影响看着舒不舒服。资料库上传体验也动了：上传成功可以一键跳转查看，已经传过的文件不再重复上传，后者解决的是个常见的烦心事，用户忘了传过某个文件又传一遍，浪费时间还让资料库越堆越乱。挺烦人。5.3.13 还修了子任务一直停在准备中，对话里 WeData 图表显示不出来，思考过程中代码块文字重叠这些功能性 Bug，海外版也同步修了提示词增强不可用，历史消息日期不按语言显示，关于页跳转错误。</p>
<p>连着两天发版。能看出 WorkBuddy 走的是小步快跑的路线，每个版本不大，但更新频繁、问题修得快。5.3.11 那波 74 条大更新之后，5.3.12 和 5.3.13 分别在移动端协同和灵感分享上做深化，整体是在大版本基础上做精细化打磨，等于是先把底座铺好再一点点抠细节。从趋势看，AI 办公工具的竞争正在从功能数量转向使用体验，谁能把移动端协同做得更顺，把技能分享做得更简单，把弱网休眠这些边缘场景处理得更稳，谁就能在体验上拉开差距。</p>
