# WorkBuddy第一个任务：从登录到出结果，新手照做就行

> 原文链接：[https://www.laoshoucun.com/jiaocheng/2972](https://www.laoshoucun.com/jiaocheng/2972)

<p>装好 <a href="https://www.laoshoucun.com/workbuddy" target="_blank" rel="noopener">WorkBuddy</a> 之后，第一件事不是研究功能，是把一个任务从头到尾跑一遍，你就懂它怎么用了。</p>
<p>先登录。点「登录」跳浏览器，用微信扫码。个人用户选个人登录，买了企业版的选企业登录，别选错入口。</p>
<p><img loading="lazy" decoding="async" src="https://cdn.laoshoucun.com/web/2026/09/20260902154354_064207.png" alt="新建任务" width="600" height="395"></p>
<p>然后新建任务。回到 WorkBuddy，点「新建任务」。这里有个细节容易搞混：在手机端发起的任务是去「助理」里看的，电脑端新建的任务才在这个工作台里跑，两边入口不一样。</p>
<p><img loading="lazy" decoding="async" src="https://cdn.laoshoucun.com/web/2026/09/20260902154411_547679.png" alt="查看任务结果" width="600" height="395"></p>
<p>接着描述任务。在对话框里把你的要求说清楚，越具体越好。比如「把这份销售数据做成分析报告，带图表」，比光说「帮我分析数据」强，它知道往哪个方向干。</p>
<p>发送之后就是等。点发送，WorkBuddy 开始自己拆步骤、执行，右侧窗口能实时看到它的进度。</p>
<p>最后看结果。打开右侧窗口，生成的目标文件在「产物」里能找到，任务过程中产生的其他文件在「概览」的「工作空间文件」里。拿到结果核对一遍，这个任务就算跑通了。</p>
<p>这一圈走下来，你对它的工作方式就有数了：你说需求，它拆步骤，你只看结果。后面那些功能，都是在这个基础上加花活。</p>
