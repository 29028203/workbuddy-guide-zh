# WorkBuddy 中文使用指南

## WorkBuddy介绍

WorkBuddy 是腾讯云 CodeBuddy 团队基于 OpenClaw 开源生态打造的全场景办公 AI Agent 助手，被大家亲切称为"腾讯办公龙虾"。它无需复杂配置，桌面端静默运行，自带腾讯安全沙箱防护；支持桌面端/企业微信直连绑定，无论你身处何地，通过企业微信或电脑发送指令，就能让本地电脑自动完成文档生成、数据可视化、PPT 制作等工作，数据安全不出本地，适合职场办公、内容创作、数据分析等场景使用。产品内置腾讯混元等优质国产大模型，拥有全场景办公技能生态与超强上下文理解能力，还能一键关联已安装的 OpenClaw，是真正懂职场需求、帮你高效完成工作的智能同事。

## WorkBuddy特点

- 腾讯云出品：专注办公场景，贴合国内职场习惯。
- 兼容 OpenClaw 生态：可复用技能库，快速扩展办公能力。
- 全场景办公覆盖：一句话完成文档、数据、设计等多类工作。
- 企业微信直连：职场场景下便捷触发，提升办公效率。
- 桌面级交互：直接操控本地文件与应用，交付可验收成果。
